## Key data flow
```
MacBook (live-bridge running) → Supabase (cloud) → all users' browsers (Live tab, auto-refresh every 30s)
```
- Bridge only needed DURING sessions (quali, race, sprint, FP)
- Between sessions: OpenF1 + Jolpica APIs work fine without bridge
- Mid-race: "Generate Live Prediction" button (Live tab) — always fresh, never cached, uses bridge positions + pre-race prediction for comparison
- Pre-race: "Generate" button — stage-aware cache (afterQuali, beforeQuali, etc.), Force Regenerate to bypass

## Prediction caching
- `lastPrediction` — in-memory, current prediction object
- `cachedPredictions` — array loaded from Supabase on init
- Stage keys: `beforeQuali`, `afterQuali`, `beforeSprintQ`, `afterSprintQ`, `afterSprint`, `final`
- `getCurrentStage(race)` — pure time-based, returns current stage
- `forceFreshPrediction()` — sets `window._forceFreshPrediction = true`, bypasses cache
